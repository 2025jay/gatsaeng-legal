개인정보처리방침

갓생습관(이하 "회사")은 「개인정보 보호법」 및 관련 법령을 준수하며, 이용자의 개인정보 보호를 위해 다음과 같이 처리방침을 수립·공개합니다.

1. 수집하는 개인정보 항목

가. 회원가입 시 (소셜 로그인)

  • 필수: 이메일, 이름(닉네임), 프로필 사진 URL
  • 수집 출처: 구글 / 애플 / 네이버 (이용자 동의 후 제공)

나. 서비스 이용 중 자동 수집

  • 챌린지 참여 기록, 인증 사진, 포인트 내역, 래플 응모 기록
  • 접속 일시, 단말기 정보(OS 종류·버전), IP 주소

다. 수집하지 않는 정보

  • 비밀번호 (소셜 로그인 제공자가 관리)
  • 주민등록번호, 휴대폰 번호
  • 결제 정보 (서비스 내 결제 없음)
  • 정밀 위치 정보

2. 개인정보의 수집·이용 목적

항목 이용 목적
이메일, 이름 회원 식별, 알림 발송, 고객 응대
프로필 사진 앱 내 프로필 표시
챌린지/인증 기록 챌린지 진행 관리, 포인트 지급
인증 사진 챌린지 인증 검증
래플 응모 기록 추첨, 당첨자 안내
접속 정보 서비스 개선, 부정 이용 방지

3. 개인정보 보유·이용 기간

  • 회원 탈퇴 시: 즉시 파기 (회원탈퇴 기능 제공)
  • 단, 관계 법령에 따라 보관 필요 시 아래 기간 보관:
  • 부정 이용 기록: 1년 (정보통신망법)
  • 접속 로그: 3개월 (통신비밀보호법)

4. 개인정보의 제3자 제공

원칙적으로 제3자에게 제공하지 않습니다. 단, 다음 경우 예외: - 이용자가 사전 동의한 경우 - 법령에 의거하여 수사기관 등이 요구하는 경우 - 래플 당첨 시 경품 발송을 위해 협찬사에 최소 정보 제공 (이용자 동의 후)

6. 정보주체의 권리·의무 및 행사 방법

이용자는 언제든지 다음 권리를 행사할 수 있습니다:

  • 열람 요구: 처리 중인 개인정보 확인
  • 정정·삭제 요구: 잘못된 정보 수정 또는 삭제
  • 처리 정지 요구: 개인정보 처리 중단 요청
  • 회원 탈퇴: 앱 내 [프로필 → 회원탈퇴] 통해 즉시 가능

권리 행사는 개인정보 보호 책임자 이메일로 요청 가능합니다.

7. 개인정보의 파기

  • 파기 절차: 회원 탈퇴 또는 보유 기간 경과 시 즉시 파기
  • 파기 방법:
  • 전자적 파일: 복구 불가능한 방법으로 영구 삭제
  • 종이 문서: 분쇄 또는 소각

8. 개인정보의 안전성 확보 조치

회사는 다음 조치를 취하고 있습니다:

  • 관리적 조치: 내부 관리 계획 수립, 접근 권한 최소화
  • 기술적 조치:
  • 비밀번호 암호화 저장 (제3자 OAuth 위임)
  • 접속 토큰 보안 저장 (iOS Keychain / Android Keystore)
  • 통신 구간 암호화 (HTTPS/TLS)
  • 접근 권한 관리 (관리자 권한 분리)
  • Rate Limiting 적용
  • 물리적 조치: 클라우드 사업자(Supabase) 보안 정책 준수
